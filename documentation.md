# Документация Mini-Framework

Добро пожаловать в документацию **Mini-Framework** — крошечного реактивного JavaScript-фреймворка, созданного для демонстрации основных концепций современной веб-разработки.

## Особенности

### 1. Абстракция DOM (Virtual DOM)
Фреймворк использует Virtual DOM для представления интерфейса в виде дерева объектов JavaScript. Эта абстракция позволяет фреймворку вычислять разницу между текущим и желаемым состоянием, обновляя только те части реального DOM, которые изменились.

### 2. Управление Состоянием
Mini-Framework реализует реактивную систему состояния с использованием ES6 Proxy. Когда вы обновляете состояние приложения, фреймворк автоматически обнаруживает изменения и запускает перерисовку интерфейса.

### 3. Система Роутинга
Встроенный роутер на основе хэшей синхронизирует представление приложения с URL. Это позволяет легко создавать навигацию в Single Page Applications (SPA).

### 4. Обработка Событий
Вместо прямого использования нативного `addEventListener`, фреймворк предоставляет кастомный способ определения обработчиков событий внутри определений виртуальных элементов.

## Примеры Кода

### Создание Элемента
Для создания элемента используйте функцию `h` (hyperscript).
```javascript
import { h } from './framework/vdom.js';

const element = h('div', { class: 'my-class' }, 'Привет, мир!');
```

### Создание События
События определяются путем передачи свойства `onEventName` в функцию `h`.
```javascript
h('button', { 
    onClick: () => alert('Нажато!') 
}, 'Нажми меня');
```

### Вложенность Элементов
Элементы могут быть вложенными, если передать их в качестве детей в функцию `h`.
```javascript
h('div', { class: 'container' },
    h('h1', {}, 'Заголовок'),
    h('p', {}, 'Это вложенный параграф.')
);
```

### Добавление Атрибутов
Атрибуты передаются как объект «ключ-значение» во втором аргументе функции `h`.
```javascript
h('input', { 
    type: 'text', 
    placeholder: 'Введите ваше имя',
    value: 'Иван Иванов'
});
```

## Почему все работает именно так

### Цикл Virtual DOM
1. **Определение**: Вы определяете UI как функцию состояния.
2. **Виртуальный узел**: Функция `h` создает легкий JS-объект, представляющий узел DOM.
3. **Патчинг (Patching)**: При изменении состояния создается новое дерево Virtual DOM. Функция `patch` сравнивает новое дерево со старым (diffing) и применяет минимальные обновления к реальному DOM.

### Реактивность
Используя `Proxy` для управления состоянием, мы перехватываем каждую операцию «set». Это позволяет нам точно знать, когда данные изменились, без необходимости вручную вызывать функцию `render()`. Эта инверсия контроля и делает библиотеку фреймворком.

### Роутинг
Роутер слушает событие `hashchange`. При изменении URL (например, с `#/` на `#/todo`) роутер обновляет состояние приложения, что, в свою очередь, запускает перерисовку соответствующего вида.
